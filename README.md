# 开屏广告走开

一个面向 iOS App 的开屏广告辅助跳过插件，复刻“王跳跳”的使用思路。插件通过扫描 UIKit 视图、端侧 OCR、录制坐标和点击兜底来尝试跳过开屏广告，不需要修改宿主 App 的源码。

> 本项目只提供插件源码和构建配置，不包含原版“王跳跳”二进制。

## 功能

- 扫描当前界面中的“跳过”“Skip”等按钮和文字。
- 使用 Vision OCR 识别截图中的跳过文字，支持简体中文、繁体中文和英文。
- 录制自定义坐标，并保存坐标对应的控件特征，减少页面变化时的误触。
- 依次尝试按钮动作、点击手势、控件事件和模拟触摸。
- 在其他方式都没有命中时，使用一次右上角兜底点击。
- 清理常见的更新、通知、评分和青少年模式弹窗，不处理支付、删除和退出登录类弹窗。
- 支持全程监听，处理中途出现的广告或弹窗。
- 设置面板支持录制、查看、撤销和清除坐标。
- 自动检查 GitHub Tag，有新版本时提醒，不会自动下载、替换或重新注入 dylib。

## 防误触

开屏阶段不会立即进行盲点点击。应用启动或回到前台后，首轮检查会延迟约 2 秒，给页面布局和转场留出稳定时间。

普通新窗口、键盘窗口和系统窗口出现时，不会重新启动一轮高频盲点点击。只有应用启动和回到前台时才会启动新的检查会话。

```mermaid
flowchart LR
    A[启动或回到前台] --> B[等待约 2 秒]
    B --> C[扫描跳过按钮]
    C -->|未命中| D[OCR 识别]
    D -->|未命中| E[录制坐标]
    E -->|未命中| F[右上角兜底]
```

## 设置

设置面板通过启动提示或三指长按打开。设置只对当前注入的应用生效。

“功能开关”默认收起，目前包含：

- **文字识别**：使用截图识别“跳过”文字。
- **右上角兜底**：其他方式都没有找到目标时，尝试点击右上角。
- **弹窗清理**：关闭常见的更新、通知和评分弹窗。
- **全程监听**：处理使用过程中后来出现的广告和弹窗。

自动检查更新和三指长按默认开启，不单独显示开关，状态会写在设置面板底部的小字中。

## 安装

### 侧载注入

1. 从 [v0.0.4 Release](https://github.com/susu123oss/adgo/releases/tag/v0.0.4) 下载 `SplashAway.dylib`。
2. 注入目标 App 前，先移除旧的 `AdSkip.dylib`、`SplashAway.dylib` 或 `广告走开.dylib`，避免多个版本同时加载。
3. 注入后彻底结束目标 App，再重新打开。
4. 通过启动提示或三指长按进入设置，确认插件已经加载。

### 本地构建

项目使用 Theos 构建，目标架构为 `arm64` 和 `arm64e`：

```sh
make package
```

构建完成后：

- `dist/开屏广告走开.dylib`：侧载注入使用的双架构 dylib。
- `packages/`：本地构建的 deb 包，仅用于本地安装或测试。

## 在线更新

插件每天最多检查一次公开的 GitHub Tag：

```text
https://api.github.com/repos/susu123oss/adgo/tags?per_page=20
```

只有形如 `v0.0.4` 的稳定三段式 Tag 会参与版本比较。发现更新后，点击“在线更新”会打开对应的 GitHub Release 页面；插件不会在后台下载或替换自身。

## 发布

版本号需要同时更新以下位置：

- `control` 中的 `Version`。
- `Tweak.x` 中的 `kASVersion`。
- `CHANGELOG.md` 中对应的版本标题。

推送包含 `release/` dylib 和更新日志的提交后，`.github/workflows/release.yml` 会创建或更新对应的 GitHub Release。正式发版时只上传 dylib，不上传 deb 或 zip。

## 项目文件

.github/workflows/release.yml GitHub Release 工作流
release/                      GitHub Release 使用的 dylib
